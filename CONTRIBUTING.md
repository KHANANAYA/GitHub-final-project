# Contributing guide
Thank you for your interest in this project .We will appreciate every contribution in fixing bugs, improving in documentation , suggesting new ideas or adding new features
## How to Contribute
1.fork repository.
2.Create a new branch for your changes in it.
3. Make your changes and test them.
4.commit your changes with a clear and descriptive commit message.
5. Push your branch to your fork
6.Open a pull request which describe your all changes and why these changes are needed
## Reporting issues
If you want to find bugs or have any suggestion, open an issue which include
1.It consist of clear and descriptive title.
2.All the steps that reproduce the issue.
3.Expected behavior.
## Code style
1.write your clean , readable and well-documented code.
2. Follow the projects coding conventions.
3. Commit focused on a single change whenever possible.
## Documentation
documentation improvement are always appreciated in it .If you notice outdated or missing information in it you have to submit a pull request without any hesitation.
## Questions
If you have any question before all contribution open issue for discussion on it.
## Thank you
All contribution, bug reports, bug fixes, documentation improvement , enhancement and ideas are greatly appreciated. Thank you for helping improving this project!
